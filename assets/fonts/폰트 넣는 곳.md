# 이 폴더에 Paperlogy 폰트 파일을 넣으세요

교육장 PC마다 글꼴이 달라 보이지 않도록, 폰트 파일을 **게임과 함께 배포**합니다.

## 넣어야 할 파일 (이름 그대로)

| 파일명 | 쓰이는 곳 |
|---|---|
| `Paperlogy-4Regular.woff2` | 본문 · 설명 |
| `Paperlogy-6SemiBold.woff2` | 화면 제목 · 카드 이름 |
| `Paperlogy-8ExtraBold.woff2` | 국면 질문 · 큰 숫자 · 타이머 |

- **`.woff2` 를 권합니다.** `.ttf` 보다 파일이 3~4배 작아 교육장에서 훨씬 빨리 뜹니다.
- `.ttf` 만 구하셨다면 `.ttf` 그대로 넣어도 동작합니다. 파일명만 위와 같게 맞춰주세요.
- 세 개 다 넣지 않아도 됩니다. 넣은 굵기만 적용되고, 없는 굵기는 다른 글꼴로 대체됩니다.

## 파일이 없으면 어떻게 되나요

화면은 그대로 나옵니다. 글꼴만 **Pretendard → 맑은 고딕** 순서로 대체됩니다.
레이아웃이 깨지지는 않지만, PC마다 글자 폭이 조금씩 달라 보입니다.

## 확인하는 법

1. 파일을 넣고 브라우저에서 **Ctrl+F5** (강력 새로고침)
2. 시작 화면 제목의 글자 모양이 바뀌면 적용된 것입니다
3. 안 바뀌면 개발자도구(F12) → Network 탭에서 `Paperlogy-...` 가 **404** 인지 확인하세요.
   404면 파일명이 틀린 것입니다.

## 라이선스

Paperlogy 는 무료로 쓸 수 있는 글꼴이지만, **배포 조건은 사용하시기 전에 직접 확인**하세요.
사내 교육 자료에 폰트 파일을 포함해 배포하는 것이 허용되는지 확인이 필요합니다.

> 연결 설정은 `css/fonts.css` 에 있습니다. 파일명을 바꾸시려면 거기도 함께 고쳐야 합니다.
