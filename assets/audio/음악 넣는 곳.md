# 소리 파일

효과음 대부분은 파일이 필요 없습니다. 브라우저가 그 자리에서 만듭니다.
**배경음악 두 곡과 돌발 알람만** 파일을 씁니다.

## ⚠ 왜 확장자가 `.m4a` 인가요

**회사 보안정책이 이 공유폴더에 `.mp3` · `.wav` · `.ogg` 쓰기를 막습니다.**
직접 넣어보시면 "액세스가 거부되었습니다" 가 뜹니다. 실제로 확인한 결과입니다.

| 확장자 | 쓰기 |
|---|---|
| `.mp3` `.wav` `.ogg` `.mp4` | ❌ 차단 |
| **`.m4a`** `.webm` `.bin` `.dat` | ✅ 허용 |

그래서 **파일 내용은 mp3 그대로 두고 이름만 `.m4a`** 로 넣었습니다.
게임이 파일 앞부분을 직접 읽어 진짜 형식을 알아낸 뒤 브라우저에 알려주므로,
확장자와 내용이 달라도 정상 재생됩니다.

## 지금 들어 있는 파일

배경음악은 **시대나 국면이 아니라 '어디까지 왔는가'** 로 갈립니다. 두 곡뿐입니다.

| 파일 | 받은 이름 | 언제 나오나 |
|---|---|---|
| `music-normal.m4a` | 평상시 노래 | **표지부터 회고까지** — 진행 방법 · 시대 설명 · 조별 결정 · 시간 흐름 · 돌발상황 · 국면 결과 · DRB 실제 · 산업 지도 · 순위 · 시상 · 회고 |
| `music-finale.m4a` | 엔딩곡 | **"우리는 이렇게 걸어왔습니다"(회사 사진) 부터 "그리고 2026년부터는"(맺음말) 까지** |
| `shock.m4a` | Alarm Clock | **돌발상황이 뜨는 순간 한 번** (배경음악 위로 겹칩니다) |

- **평상시 노래는 6개 국면 전부 같은 곡입니다.** 국면이 넘어가도 곡이 바뀌지 않으므로
  중간에 끊기거나 처음으로 되감기지 않습니다.
- **두 곡 다 무한 반복입니다.** 곡이 2분이고 국면이 5분이어도 끊기지 않습니다.
- 회고 → 회사 사진으로 넘어갈 때만 곡이 바뀝니다.
  앞 곡이 천천히 사라지고(0.9초) 엔딩곡이 올라옵니다(1.4초).
- 돌발상황에서는 음악이 작아지고(0.07) 알람이 그 위로 울립니다.

> `music-lapse.m4a`(시대흐름)와 `music-ending.m4a`(엔딩)는 지금 쓰지 않습니다.
> 파일은 그대로 두었으니 되살리려면 아래 표에 다시 적으면 됩니다.

## 어느 화면에서 어느 곡이 나오는지 바꾸려면

`data/config.js` 의 `audio.musicByScreen` 표에서만 바꾸면 됩니다.

```js
musicByScreen: {
  intro:  "normal",  howto:  "normal",  briefing: "normal",  decisions: "normal",
  lapse:  "normal",  event:  "normal",  phase:    "normal",  actual:    "normal",
  map:    "normal",  standings: "normal",  award:  "normal",  reflect:  "normal",

  finale: "finale",  closing: "finale"
}
```

예를 들어 시상부터 엔딩곡을 깔고 싶으면 `award: "normal"` 을 `award: "finale"` 로 바꿉니다.
표에 없는 화면은 자동으로 `normal` 입니다.

## 곡 자체를 바꾸려면 — 파일을 옮기지 마세요

**같은 이름으로 덮어쓰면** 끝입니다. `.mp3` 파일이라면 이름만 `.m4a` 로 바꿔서 넣으세요.

| 바꾸고 싶은 것 | 덮어쓸 파일 |
|---|---|
| 평상시 노래 | `music-normal.m4a` |
| 엔딩곡 | `music-finale.m4a` |
| 돌발 알람 | `shock.m4a` |

## 볼륨

```js
volume:      0.22,   // 평상시는 작게. 토론을 방해하면 안 됩니다
duckVolume:  0.07,   // 돌발상황 동안 이만큼으로 낮춥니다
shockVolume: 0.55    // 알람
```

**소리가 크면 여기 숫자를 낮추세요.** 0 ~ 1 사이입니다.

## ⚠ 라이선스

**사내 교육에 쓰기 전에 각 곡의 라이선스를 확인하세요.**
지금 들어 있는 곡의 출처와 조건은 파일을 주신 분이 확인해주셔야 합니다.

- `CC0` — 조건 없음. 가장 안전합니다
- `CC BY` — 출처 표시 필요. 교육 자료 끝에 곡명·작곡자를 적으세요
- YouTube 오디오 보관함 — 곡마다 조건이 다릅니다

무료 음악이 더 필요하면:
- **Openverse** — https://openverse.org/search/audio (필터 `CC0`)
- **Pixabay Music** — https://pixabay.com/music/
- **YouTube 오디오 보관함** — 채널 스튜디오 안
