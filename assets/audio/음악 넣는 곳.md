# 소리 파일

효과음 대부분은 파일이 필요 없습니다. 브라우저가 그 자리에서 만듭니다.
**배경음악과 돌발 알람만** 파일을 씁니다.

## ⚠ 왜 확장자가 `.m4a` 인가요

**회사 보안정책이 이 공유폴더에 `.mp3` · `.wav` · `.ogg` 쓰기를 막습니다.**
직접 넣어보시면 "액세스가 거부되었습니다" 가 뜹니다. 실제로 확인한 결과입니다.

| 확장자 | 쓰기 |
|---|---|
| `.mp3` `.wav` `.ogg` `.mp4` | ❌ 차단 |
| **`.m4a`** `.webm` `.bin` `.dat` | ✅ 허용 |

그래서 **파일 내용은 mp3 그대로 두고 이름만 `.m4a`** 로 넣었습니다.
게임이 파일 앞부분을 직접 읽어 진짜 형식을 알아낸 뒤 브라우저에 알려주므로,
확장자와 내용이 달라도 정상 재생됩니다.

## 곡을 바꾸려면 — 파일을 옮기지 마세요

`data/config.js` 의 `audio` 에서 **파일명만 바꾸면** 됩니다.

```js
audio: {
  bgm:   "assets/audio/track-a.m4a",   // ← 여기만 track-c.m4a 로 바꾸면 곡이 바뀝니다
  tense: "assets/audio/track-b.m4a",
  shock: "assets/audio/shock.m4a",
  bgmVolume:   0.22,     // 평상시는 작게. 토론을 방해하면 안 됩니다
  tenseVolume: 0.42,
  shockVolume: 0.55
}
```

**볼륨이 크면 여기 숫자를 낮추세요.** 0 ~ 1 사이입니다.

## 새 곡을 넣으려면

1. 받은 파일의 **확장자를 `.m4a` 로 바꿔서** 이 폴더에 넣습니다 (`.mp3` 는 차단됩니다)
2. `data/config.js` 의 `audio` 에서 파일명을 그 이름으로 바꿉니다

무료 음악은 `node tools/getmusic.js` 로 받거나 아래에서 직접 고릅니다.
- **Openverse** — https://openverse.org/search/audio (필터 `CC0`)
- **Pixabay Music** — https://pixabay.com/music/
- **YouTube 오디오 보관함** — 채널 스튜디오 안

## ⚠ 라이선스

**사내 교육에 쓰기 전에 각 곡의 라이선스를 확인하세요.**
지금 들어 있는 네 곡의 출처와 조건은 받으신 분이 확인해주셔야 합니다.

- `CC0` — 조건 없음. 가장 안전합니다
- `CC BY` — 출처 표시 필요. 교육 자료 끝에 곡명·작곡자를 적으세요
- YouTube 오디오 보관함 — 곡마다 조건이 다릅니다
